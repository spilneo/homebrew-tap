# spilneo/homebrew-tap

Homebrew casks for [spilneo](https://github.com/spilneo) projects.

## RouteBar

The quiet way to run OmniRoute on a Mac. One endpoint, your subscriptions, every model.

```sh
brew trust --cask spilneo/tap/routebar && brew install --cask spilneo/tap/routebar
```

[Casks/routebar.rb](Casks/routebar.rb) is regenerated by
[`update-cask`](.github/workflows/update-cask.yml) every six hours from the latest
[RouteBar release](https://github.com/spilneo/RouteBar/releases). Run the workflow by hand to
pick up a release right away.
